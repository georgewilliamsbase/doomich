# Админ-панель Думыча

Одностраничное приложение на React и Ant Design. Работает поверх админ-API (`/admin/v1`) Core API.
На сервере nginx раздаёт сборку по пути `/admin/`, доступ только из VPN.

## Что умеет

| Раздел | Кто видит | Что делает |
|---|---|---|
| Состояние | все | агрегированная статистика вуза, модели, очереди, резервные копии, источники расписания |
| Вуз и кампусы | все, правят администраторы | название, часовой пояс, возможности, звонки, режим имён преподавателей, кампусы, семестры |
| Группы | все | группы и подгруппы |
| Коды приглашения | администраторы | выпуск партий, листовки PDF, просмотр и отзыв кодов |
| Расписание | все | загрузка шаблона или .ics с проверкой, автоматические источники, ручная правка занятий |
| Оценки ответов | администраторы | обезличенные оценки, фильтр по неудачным |
| Блокировка | администраторы | блокировка по псевдониму |
| Журнал действий | администраторы | кто что менял |
| Модели, релизы, администраторы | суперадмин | привязки моделей к вузам и кампусам, релизы приложений, учётные записи |

Роли: `superadmin` видит все вузы, `tenant_admin` управляет своим вузом, `operator` ведёт группы и расписание.

Персональных данных студентов панель не показывает: пользователи зарегистрированы под псевдонимами,
статистика только агрегированная.

## Вход

Логин, пароль и код из приложения-аутентификатора (TOTP). На stage и prod второй фактор обязателен,
при первом входе панель показывает QR-код для настройки. Токен хранится в sessionStorage и пропадает
при закрытии вкладки, срок жизни токена 8 часов.

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173/admin/, запросы /admin/v1 уходят на localhost:8000
```

Нужен запущенный Core API (`make dev` в корне или `uvicorn` из `services/api`).
В режиме dev второй фактор не спрашивается; демо-учётка из `doomich-manage seed-demo`: `admin` / `admin-demo-pass`.

Проверки:

```bash
npm run typecheck
npm run lint
npm test -- --run
npm run build        # результат в dist/
```

Время занятий панель показывает и вводит в часовом поясе вуза, а не браузера (`src/time.ts`).
