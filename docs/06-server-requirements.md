# Требования к серверу и стоимость

← [К плану](README.md) · Связанные документы: [архитектура](05-architecture-and-stack.md), [поддержка](04-stage-4-support.md)

> Цены — ориентиры по открытым прайсам и обзорам на ноябрь 2026 (источники — в разделе 6). Перед заказом проверьте актуальную цену и полную конфигурацию: CPU, RAM, диски и канал сильно влияют на стоимость.

## 1. Профиль нагрузки пилота

| Параметр | Оценка | Комментарий |
|---|---|---|
| Зарегистрированных пользователей | ≤ 500 | Пилот одного вуза |
| Активных в день (DAU) | ≈ 200 | 40% от зарегистрированных |
| Активных в пиковый час | ≈ 60 | 30% DAU, между парами и вечером |
| Запросов в пиковый час | ≈ 600 | ≈ 10 на активного пользователя |
| Одновременных генераций LLM | 3–10, всплески до 20–30 | Ответ 300–500 токенов, длина промпта для RAG — 4–8 тыс. токенов |
| Доля голосовых запросов | ≈ 30% | Распознавание и синтез идут на GPU |
| Документы | 200–300 в неделю, в среднем 30 страниц | Разбор нагружает CPU, эмбеддинги — GPU |
| Конспекты (R1.1) | До 30–50 ч аудио в день | Распознавание GPU обычно в десятки раз быстрее реального времени |
| Навигация (R2) | До 500 определений места в день | 4–8 кадров на попытку |

Пилоту хватает одного GPU-сервера среднего класса. Главный потребитель видеопамяти — LLM.

Ко всем вариантам добавляется хранилище резервных копий в другом ЦОД (500 ГБ – 1 ТБ, ≈ 1–3 тыс. ₽/мес). Для Спринта 0 нужна почасовая аренда GPU под бенчмарк моделей — около 10–20 тыс. ₽ разово.

Число одновременных генераций — оценка. Его уточняет нагрузочный тест в Спринте 4 (R1-E10-02).

## 3. Распределение памяти GPU

**Конфигурация Б, 2× RTX 4090:**

| GPU | Что работает | Память |
|---|---|---|
| GPU 0 (24 ГБ) | vLLM: Qwen3.6-35B-A3B в 4 бит | ≈ 19–20 ГБ веса и ≈ 3–4 ГБ KV-кэш |
| GPU 1 (24 ГБ) | GigaAM-v3 (≈ 1,5), Whisper turbo (≈ 2,5), TTS (2–5), эмбеддинги (≈ 1,5), реранкер (≈ 1,5). В R2 добавляются Qwen3-VL-Embedding-2B (≈ 5) и MegaLoc с LightGlue (≈ 2) | ≈ 9–12 ГБ в R1, ≈ 16–19 ГБ в R2 |

**Конфигурация Б, 1× A100 80 ГБ:** всё на одном GPU.

| Что работает | Память |
|---|---|
| LLM в FP8 | ≈ 36 ГБ веса и ≈ 15 ГБ KV-кэш |
| Речь, эмбеддинги, навигация | ≈ 15 ГБ |
| **Итого** | **≈ 66 ГБ**, запас ≈ 14 ГБ |

Этот вариант проще в обслуживании, но дороже.

**Конфигурация А, 1× RTX 4090:**

| Что работает | Память |
|---|---|

| Речь и эмбеддинги | ≈ 8 ГБ |

Для R2-навигации этой конфигурации мало.

## 4. Программные требования

- **ОС:** Ubuntu Server 24.04 LTS (или Debian 12/13). При переезде на сервер вуза — проверить поддержку драйверов NVIDIA в Astra Linux.
- **GPU-стек:** драйвер NVIDIA актуальной ветки с поддержкой CUDA 12.8+, NVIDIA Container Toolkit, Docker Engine и Compose v2.
- **Доступ:**
  - вход только по SSH-ключам, root-вход запрещён;
  - отдельные пользователи и sudo;
  - SSH — только через WireGuard или по белому списку IP.
- **Сеть:** наружу открыты только 443 и 80 (для выпуска TLS-сертификата). Админ-панель и Grafana — только через VPN.
- **Хранилище:** раздел с данными под LUKS. Модели, данные и логи — на разных томах.
- **Служебное:** chrony (время), unattended-upgrades (обновления безопасности), fail2ban, ротация логов.

**Диск, оценка на пилот:**

| Что хранится | Объём |
|---|---|
| Модели с запасными версиями | 150–200 ГБ |
| Документы пользователей | ≈ 50 ГБ (500 × 100 МБ) |
| БД и векторы | 10–20 ГБ |
| Временное аудио лекций | ≈ 50 ГБ |
| Логи и метрики | ≈ 20 ГБ |
| Образы | ≈ 50 ГБ |
| **Итого** | **≈ 0,4 ТБ** |

1 ТБ — минимум, 2 ТБ — с запасом.

## 5. Требования к провайдеру

- ЦОД на территории РФ, провайдер — российское юрлицо. Это нужно для хранения данных в РФ и на случай требований 243-ФЗ к инфраструктуре.
- Выделенный сервер или виртуальная машина с целым GPU, без деления на доли (vGPU): производительность должна быть предсказуемой.
- Помесячная оплата, плюс возможность почасово брать дополнительный GPU на пиковые недели.
- Приватная сеть между серверами, S3-совместимое хранилище в другом ЦОД для резервных копий.
- Поддержка 24/7, SLA доступности ≥ 99,9%, замена неисправного оборудования ≤ 4 ч.
- Желательно — сегмент, готовый к требованиям 152-ФЗ. Он понадобится, если позже вуз поручит обработку персональных данных.

## 7. Когда переходить на следующую конфигурацию

| С | На | Признаки (любой) |
|---|---|---|
| А | Б | Старт закрытой беты; DAU > 100; загрузка GPU в пик > 70% три дня подряд; первый токен p95 > 2 с; начало разработки R2-навигации |
| Б | В | Решение о запуске на весь вуз; DAU > 1500; очередь к LLM в пик > 1 с; конспекты не укладываются в 15 мин на час лекции |
| В | Несколько узлов и k3s | Несколько вузов; требование отказоустойчивости без простоя; более 4 GPU |

## 8. Размещение на сервере вуза (R3)

Если вуз захочет держать «Думыч» у себя, данные физически не покидают вуз. Это сильный аргумент для приватности.

**Требования к вузу:**

- место в серверной;
- питание 1–2 кВт на GPU-сервер и охлаждение;
- канал 1 Гбит/с;
- белый IP или обратный прокси;
- VPN-доступ для команды;
- место для резервных копий.

**Оборудование** — уровня конфигурации Б или В.

**Поставка:**

- Ansible-плейбуки и Docker Compose — те же, что на арендованном сервере;
- регламенты обновления и мониторинга.

**Ответственность.** Вуз отвечает за инфраструктуру, команда — за приложение и модели. Это оформляется договором.
