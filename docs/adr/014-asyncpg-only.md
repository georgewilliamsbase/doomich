# ADR-014. Один драйвер БД для API и воркеров

Статус: принято.

API и воркеры работают с PostgreSQL через SQLAlchemy 2 и asyncpg (Apache-2.0). Воркеры Celery синхронные, поэтому задача запускает асинхронный код через `asyncio.run`. Так в проекте один драйвер и нет зависимостей под LGPL (psycopg), что упрощает проверку лицензий.
