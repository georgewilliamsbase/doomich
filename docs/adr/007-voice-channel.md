# ADR-007. Голосовой канал

Статус: принято.

WebSocket `/v1/voice`. Клиент шлёт `start`, затем аудио бинарными кадрами, затем `end`. Поддерживаются два кодека: `pcm16` (16 кГц, моно) и `opus` (пакеты по 20 мс с префиксом длины). PCM работает на всех платформах сразу, Opus включается там, где клиент может кодировать (экономит трафик примерно в 10 раз).

Сервер распознаёт речь, передаёт текст оркестратору, режет ответ на предложения и озвучивает каждое отдельно, так что звук начинается до конца генерации. Аудио обрабатывается только в памяти.

Полный протокол: [docs/api/voice-protocol.md](../api/voice-protocol.md). WebRTC вернёмся рассматривать при полном дуплексе, если задержки WebSocket не хватит.
