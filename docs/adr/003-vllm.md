# ADR-003. Инференс через vLLM

Статус: принято.

LLM, эмбеддинги и реранкер поднимаются в vLLM. Core API ходит к ним по OpenAI-совместимому API (`/v1/chat/completions`, `/v1/embeddings`) и по `/v1/rerank`. Адаптеры LoRA разных вузов подгружаются в один процесс vLLM (`--enable-lora`), имя адаптера передаётся в поле `model`.

Альтернативы: SGLang (сопоставим, меньше опыта в команде), llama.cpp/Ollama (подходит для ноутбуков разработчиков, профиль `lite` в compose), TGI (меньше активности проекта).

Следствие: замена модели сводится к смене конфигурации и прогону оценочных наборов.
