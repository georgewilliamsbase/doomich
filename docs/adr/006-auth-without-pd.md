# ADR-006. Регистрация без персональных данных

Статус: принято.

Вход по псевдониму и паролю. Регистрация только по коду приглашения, код определяет вуз, роль и, при желании, группу. Пароль и код восстановления хранятся как хэши Argon2id. Access-токен JWT живёт 15 минут, refresh-токен 30 дней, при каждом обновлении выдаётся новый, а повторное использование старого отзывает всю цепочку сессии.

Телефон, e-mail, ФИО и дата рождения не принимаются API вообще: в схемах запросов этих полей нет. Псевдоним уникален в пределах установки, чтобы при входе не нужно было выбирать вуз.

Привязка "аккаунт = конкретный преподаватель из расписания" хранится только на устройстве.
