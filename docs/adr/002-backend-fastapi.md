# ADR-002. Бэкенд: Python 3.12, FastAPI, модульный монолит

Статус: принято.

Core API (`services/api`) это один сервис с модулями: аккаунты, вузы, чаты и оркестратор, расписание, документы, лекции, курсы, кампус, голосовой шлюз, админ-API. Фоновые задачи (Celery) используют тот же Python-пакет и запускаются из того же образа другой командой. Тяжёлые модели вынесены в отдельные сервисы: vLLM, ASR, TTS, навигация.

Причины: вся команда знает Python, ML-экосистема на Python, FastAPI даёт OpenAPI из кода, а модульный монолит проще микросервисов для 3-5 человек. Если модулю понадобится масштабироваться отдельно, его можно вынести, потому что модули общаются через сервисный слой, а не через чужие таблицы напрямую.
