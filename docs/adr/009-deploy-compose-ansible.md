# ADR-009. Развёртывание: Docker Compose и Ansible

Статус: принято.

Один узел (конфигурация А) или два (Б: прикладной и GPU). Ansible готовит сервер (пользователи, firewall, Docker, драйвер NVIDIA, LUKS, WireGuard, бэкапы) и раскатывает стек Compose. Stage и prod это отдельные проекты Compose со своими БД, модельный слой общий.

Kubernetes (k3s) рассматриваем при нескольких GPU-узлах или требовании отказоустойчивости. Образы при этом те же.
