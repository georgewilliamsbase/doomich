# ADR-010. Без сторонней аналитики и облачных SDK

Статус: принято.

В приложениях нет Firebase, AppMetrica, Google Analytics, рекламных SDK и Google FCM. Ошибки уходят на свой GlitchTip через Sentry-совместимый протокол без IP и содержимого. Уведомления делаются фоновой проверкой и локальными уведомлениями. Метрики продукта считаются на сервере только агрегатами.
