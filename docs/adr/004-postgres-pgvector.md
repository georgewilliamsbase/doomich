# ADR-004. PostgreSQL + pgvector + полнотекстовый поиск

Статус: принято.

Векторы фрагментов хранятся в pgvector (индекс HNSW, косинусное расстояние), полнотекстовый индекс строится по конфигурациям `russian` и `english`. Гибридный поиск объединяет оба списка через RRF, потом результат уточняет реранкер. Изоляция пользователей и вузов обеспечивается Row-Level Security.

Отдельная векторная БД (Qdrant, OpenSearch) не нужна на объёмах пилота и даже всего вуза: меньше сервисов, транзакции и удаление данных в одном месте.

Размерность эмбеддингов фиксирована: 1024 (подходит и Qwen3-Embedding, и BGE-M3). Смена модели эмбеддингов требует переиндексации, для этого есть фоновая задача `reindex_tenant`.
