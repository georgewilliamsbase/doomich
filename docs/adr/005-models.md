# ADR-005. Набор моделей

Статус: предложено. Окончательный выбор делается по итогам бенчмарка в Спринте 0 (`ml/`, команда `dml bench`).

Кандидаты по умолчанию в конфигурации:

| Компонент | По умолчанию | Запасной вариант |
|---|---|---|
| LLM | Qwen3.6-35B-A3B (конф. Б), Qwen3.5-9B (конф. А) | GigaChat 3 Lightning |
| ASR RU | GigaAM-v3 | T-one |
| ASR EN | Whisper large-v3-turbo (faster-whisper) | |
| TTS | по бенчмарку, сервис принимает любую модель через адаптер | Kokoro-82M |
| Эмбеддинги | Qwen3-Embedding-0.6B | BGE-M3 |
| Реранкер | Qwen3-Reranker-0.6B | bge-reranker-v2-m3 |
| Место по фото | MegaLoc / DINOv2 | базовый CPU-бэкенд на OpenCV |

Каждая выбранная модель получает паспорт в реестре (`ml/registry/`): версия, лицензия, хэш весов, квантование, метрики. Модели с некоммерческими лицензиями не допускаются, это проверяет `dml license-check`.
