# Думыч (Doomich)

ИИ-ассистент для студентов и преподавателей: приложение для Android и ПК (Windows, Linux) с текстовым и голосовым чатом, расписанием, ответами по документам, конспектами лекций и навигацией по кампусу. Тяжёлые модели работают на своём сервере проекта или вуза, внешние ИИ-облака не используются. Регистрация без персональных данных: псевдоним, пароль и код приглашения.

План проекта и проектные решения лежат в [`docs/`](docs/README.md), архитектурные решения в [`docs/adr/`](docs/adr/README.md).

## Что где лежит

```text
apps/
  mobile/      Flutter, приложение для Android (позже iOS)
  desktop/     Flutter, приложение для Windows и Linux (позже macOS)
  admin/       React + TypeScript, админ-панель
  site/        статический сайт: загрузка, инструкции, юридические документы
packages/
  doomich_api/   Dart: модели API (генерируются из OpenAPI), HTTP, SSE, голосовой протокол
  doomich_core/  Dart: состояние, локальная БД, репозитории, голосовая сессия
  doomich_ui/    Dart: тема, локализация RU/EN, общие экраны и виджеты
services/
  api/         FastAPI: аккаунты, вузы, чаты и оркестратор, расписание, документы,
               лекции, курсы, кампус, голосовой шлюз, админ-API, фоновые задачи Celery
  asr/         сервис распознавания речи (GigaAM-v3, Whisper)
  tts/         сервис синтеза речи и нормализации текста
  nav/         сервис определения места по фото
ml/            ML-платформа: датасеты, дообучение, оценка, реестр моделей, выкатка по вузам
infra/         docker compose, nginx, ansible, мониторинг, резервные копии
tools/         генерация клиента из OpenAPI, проверка лицензий и прочие скрипты
docs/          план, ADR, описание API, регламенты, модель угроз
```

## Быстрый старт для разработчика

Нужны Docker с Compose v2, Python 3.12+, [uv](https://docs.astral.sh/uv/), Node.js 22 и Flutter 3.47.

```bash
make dev
```

Команда поднимает PostgreSQL с pgvector, Valkey, Core API, воркеры и ИИ-сервисы в режиме заглушек (GPU не нужен), применяет миграции и создаёт демо-вуз с кодом приглашения. Код выводится в конце.

Дальше можно запустить клиент:

```bash
cd apps/mobile && flutter run
```

```bash
cd apps/desktop && flutter run -d linux
```

Подробнее про каждый компонент написано в его README.

## Тесты

```bash
make test
```

Запускает тесты бэкенда (нужен PostgreSQL с pgvector, см. `services/api/README.md`), ИИ-сервисов, ML-платформы, админки и Dart-пакетов.
