# Сервис синтеза речи

Нормализация текста (числа с согласованием, даты, время, единицы, сокращения, аббревиатуры), ударения по словарю и синтез выбранной моделью. Ответ в WAV или Ogg/Opus.

| Бэкенд | Что это |
|---|---|
| `openai_speech` | любой сервер с OpenAI-совместимым `/v1/audio/speech`: так подключается модель, выбранная в бенчмарке (Qwen3-TTS, ESpeech-TTS-1 и т. п.) |
| `kokoro` | Kokoro-82M через kokoro-onnx, работает на CPU |
| `chatterbox` | Chatterbox Multilingual на PyTorch |
| `mock` | тон вместо речи, для тестов |

Модели с некоммерческими лицензиями (Silero TTS, XTTS-v2, F5-TTS-ru) не подключаем.

## API

- `POST /v1/synthesize` `{text, lang, voice, speed, format: wav|ogg_opus, tenant}`; длительность в заголовке `X-Audio-Duration`.
- `POST /v1/normalize` `{text, lang}`: что именно уйдёт в модель. Удобно для разбора жалоб на произношение и для оценочного набора из 40 фраз.

## Ударения

Общий словарь встроен в `stress.py`. Словари вузов (названия корпусов, фамилии, термины) лежат в `TTS_DICTS_DIR/<slug>.tsv`, по строке `слово<TAB>форма с + перед ударной гласной`. Формат меток для модели задаёт `TTS_STRESS_STYLE`: `plus`, `acute` или `none`.

Короткие фразы кэшируются на диске (`TTS_CACHE_DIR`).
